# MAPA DE CONOCIMIENTO CENTRAL (KNOWLEDGE MAP)

> **Inspiración**: Arquitectura *LLM Wiki* (Andrej Karpathy) y *RSC Brain* (Eric Risco).  
> **Propósito**: Servir como índice unificado y punto de entrada para que DeepSeek Harness (y cualquier agente) mantenga contexto persistente entre sesiones sin pérdida de memoria.
